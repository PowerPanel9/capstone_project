Mockup B — Request/Response Flow

Best for teaching full-stack flow

1) Client App

  • React views and components
  • Axios + fetch for HTTP calls
  • Socket.IO client for live chat updates
  • Stripe.js checkout confirmation

2) Express API

  • Route handlers for listings, users, payments
  • JWT middleware for protected requests
  • Multer upload handling
  • AI service orchestration and MCP agent route

3) Data + Services

  • Prisma ORM to PostgreSQL
  • Stripe Connect and webhook events
  • AWS S3 for image storage
  • OpenAI / Anthropic / EmailJS / Google OAuth
