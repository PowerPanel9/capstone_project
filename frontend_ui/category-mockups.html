Option B
Fade-edge carousel Fixes the bug · minimal change
Same layout as today but adds a soft CSS fade (mask) at the right edge. Partial tiles dissolve into white instead of hard-cutting — so the eye never sees a chopped icon. Also adds a subtle gradient behind the arrow button. The smallest change to fix the visual problem.

Option C
Scrollable pill chips Redesign · recommended
Replaces the big icon tiles with compact horizontal pill chips. Each chip shows a small emoji + label. No arrows needed — users swipe/drag naturally. Fade on the right signals overflow. Much less vertical space, and completely immune to the half-tile bug because chips are just text — they reflow gracefully. Similar to how category pills work on Airbnb and DoorDash.
